# todo-management-app

A modern and responsive Todo Management Web Application built to help users organize daily tasks efficiently. The application provides a clean user interface with task creation, tracking, and management features for better productivity.

---

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive UI design
- Simple and user-friendly interface
- Real-time task updates
- Lightweight and fast performance

---

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages
